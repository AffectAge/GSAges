# Запуск хода из ячейки

Лист: `Управление`. Ячейка запуска: `B2`.
`TRUE` запускает один ход; `FALSE` ничего не запускает.
Можно использовать стандартный флажок или вручную вводить TRUE/FALSE.

## Быстрый запуск с телефона

Сначала один раз выполнить INSTALL_GAME_TURN_EDIT_TRIGGER в панели скриптов и подтвердить разрешения.

1. Создать лист `Управление`.
2. Внести в `B2` значение `FALSE`.
3. При необходимости запустить ход, изменить `B2` на `TRUE`.
4. Скрипт сбрасывает `B2` в `FALSE`; результат появляется в `B3`, время — в `B4`.
   Эти три ячейки должны быть доступны для записи и не содержать игровых данных.

Для автоматического создания листа вызвать `INITIALIZE_GAME_TURN_CONTROL()`
или пункт меню «Игровой движок → Создать управление ходом».
Если лист уже существует, функция его не перезаписывает.

## Для длительных ходов

Простой `onEdit` только показывает статус настройки и не выполняет ход.
Для запуска из листа владелец должен один раз запустить
`INSTALL_GAME_TURN_EDIT_TRIGGER()` в редакторе Apps Script и подтвердить разрешения Google.
Также доступен пункт «Игровой движок → Включить запуск по флажку».
После установки ход выполняет установленный триггер; простой обработчик показывает ожидание.
30-секундный лимит простого onEdit не применяется к расчёту. Остаётся установленный Google
предел одного выполнения (обычно 6 минут); код не может отключить эту квоту.
Расчёт ходов дольше этого предела потребует отдельной архитектуры с контрольными точками.
Обновление кода через GitHub не требует повторной установки триггера.
Если триггер удалён, повторный запуск INSTALL_GAME_TURN_EDIT_TRIGGER восстанавливает его,
даже при сохранившейся отметке в свойствах проекта. Повторный запуск с исправным триггером
не создаёт дубликаты у текущего пользователя. Триггеры других пользователей Google не показывает;
общая блокировка и сброс запроса защищают от повторного выполнения.

Если B3 показывает «Ожидается установленный триггер», но ход не начинается:
запустите INSTALL_GAME_TURN_EDIT_TRIGGER из панели скриптов под владельцем книги,
подтвердите запрошенные Google разрешения, затем измените B2 с FALSE на TRUE.
Запуск этой функции устанавливает обработчик, но не обрабатывает игровой ход.
Простая загрузка кода из GitHub не создаёт триггер в Google-аккаунте.

Если выполнение принудительно прервано Google, результат может остаться «Выполняется ход…».
Перед повторной попыткой следует проверить журнал и состояние движка:
ошибка при сохранении данных не гарантирует откат уже выполненных записей.

## Поведение

- Учитывается только прямая правка одной ячейки B2 нужного листа. Поддерживаются TRUE и ИСТИНА, включая пробелы; при отсутствии event.value проверяется значение ячейки.
- Формулы, изменения через API и записи из других скриптов не запускают ход.
- Повторная доставка события не создаёт второй ход: запрос сбрасывается под блокировкой.
- Общая блокировка защищает от одновременного запуска через меню или флажок.
  Новое событие во время занятой блокировки не ставится в очередь.
- При обычной ошибке B2 остаётся FALSE, а B3 содержит причину; ошибка также попадает в журнал движка.
- Названия листа и адреса ячеек настраиваются в `GAME_TURN_CONTROL_CONFIG`.
- Любой редактор книги с правом записи в B2 может запустить ход.
  Чтобы ограничить круг игроков, владелец может защитить диапазон B2 средствами Google Таблиц.

Проверены сценарии TRUE/FALSE, дубликатов событий, формул, другой ячейки,
массовых правок, занятой блокировки и сброса запроса при ошибке.
Реальный игровой ход при публикации кода не запускается.

Документация Google: https://developers.google.com/apps-script/guides/triggers
