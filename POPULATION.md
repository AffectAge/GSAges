# Базовая система населения

Данные: столбец `Население` внутри существующего именованного диапазона `Игровые_данные`.
Добавьте этот заголовок и включите его колонку в границы диапазона.
Каждая непустая ячейка — JSON-массив из одной или нескольких групп:

```json
[{"id":"pop_1","provinceId":1,"race":"Люди","culture":"italian","religion":"catholic","men":1000,"women":1000,"total":2000,"birthRate":0.035,"deathRate":0.025}]
```

## Создание

Шаблон `POPULATION_TEMPLATE_GENERATOR_CONFIG` находится в `Uttilities.gs`,
рядом с шаблоном провинций. Начальная численность: 10000 мужчин и 10000 женщин;
раса Люди, культура Примитивная культура, религия Анимизм. Измените шаблон до генерации.

Вызовите `GENERATE_INITIAL_POPULATION()` в редакторе Apps Script
или «Игровой движок → Создать население провинций».
Создаётся одна группа для каждой существующей провинции, у которой нет населения.
Если у провинции уже есть хотя бы одна группа (включая нулевую), она пропускается.
Повторный запуск не сбрасывает население и не создаёт дубликаты.
Все провинции учитываются независимо от типа местности; фильтра по водным типам нет.
Генерация не запускает ход. При нехватке места ничего в игровом диапазоне не записывается,
а ошибка направляется в журнал движка. Команда записывает только колонку населения.

## Расчёт хода

Параметры расположены в `GAME_RULES.population`:
`yearsPerTurn: 1` означает один год на ход.
Поле `race` — непустое название расы, например «Люди» или «Эльфы».
Если в старой группе поле отсутствует, при чтении применяется `defaultRace: 'Люди'`.
Оно записывается при успешном сохранении хода; уже указанная раса сохраняется.
Расу новых групп задаёт шаблон. Пока раса не влияет на коэффициенты демографии.
Общие для полов годовые коэффициенты записаны в каждой группе:
`birthRate` — рождения, `deathRate` — смерти.
Стартовые значения 0.035 и 0.025 — настраиваемая базовая модель из обсуждения;
это не точное воспроизведение зависимых от достатка коэффициентов Victoria 3.

Для мужчин и женщин отдельно:
`max(0, floor(count + count * birthRate * yearsPerTurn - count * deathRate * yearsPerTurn))`.
Дробная часть итоговой численности теряется. Дробные остатки не хранятся.
Общее количество пересчитывается как `men + women`.
При одинаковых коэффициентах пропорции полов приблизительно сохраняются;
округление может давать небольшое отклонение. Для очень маленьких групп даже небольшой
отрицательный результат изменения может уменьшить целую численность на один.

Процессор `POPULATION` имеет приоритет 850.
Другие функции могут изменять коэффициенты группы до него; демография их не сбрасывает.
Финальный валидатор повторно проверяет/упаковывает население после всех процессоров.
Применяется проверка целых безопасных чисел, уникальных id, существующих provinceId,
расы, культуры, религии, суммы полов, неотрицательных конечных коэффициентов.

## Вместимость

Целые группы распределяются алгоритмом first-fit decreasing: крупные группы первыми.
В длине учитываются весь JSON группы, скобки массива и запятые; предел — 48000 символов
либо меньший `GAME_TURN_CONFIG.maxJsonCellCharacters`.
Это детерминированная практическая упаковка, без гарантии минимального числа ячеек.
Неиспользованные ячейки становятся пустыми. Другие колонки не переставляются.
Адрес ячейки группы может меняться: связывать её следует по id/provinceId.

Если группа сама превышает предел либо упаковке не хватает строк, ход останавливается
до сохранения игровых диапазонов и увеличения номера хода. Журнал получает сообщение
с причиной и необходимым/доступным количеством ячеек.
Расширьте именованный диапазон, а не только лист.
При этом общие ограничения движка на частичные записи при ошибках самого Google API
остаются: упаковка предотвращает переполнение до записи, но не является транзакцией Google Sheets.

## Проверки

`node tests/population.test.cjs`

Проверяются отдельные расчёты полов, отбрасывание дробей, сокращение до нуля,
невалидные группы/дубликаты, точные границы JSON, несколько групп в ячейке,
генерация без дубликатов и перезаписи других колонок, отсутствие сохранения
при переполнении и запись ошибки в журнал без увеличения хода.
